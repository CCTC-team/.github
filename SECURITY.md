# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report vulnerabilities privately via GitHub's private security advisories:

<https://github.com/CCTC-team/.github/security/advisories/new>

If you cannot use GitHub advisories, email <cuh.cctu-ct-prog@nhs.net>. 

Please include:

- A description of the issue and the impact you believe it has
- Steps to reproduce, or a proof of concept
- The affected repository, component, and version / commit
- Any suggested remediation

## What to expect

- We aim to acknowledge reports within **2 working days**.
- We will keep you informed of progress while we triage, fix, and disclose.
- Once a fix is available we will coordinate public disclosure with you.

## Scope

This policy applies to all repositories owned by the `CCTC-team` GitHub organisation,
including production clinical systems, supporting libraries, and internal tooling.

## Patient data

If a vulnerability involves actual or suspected exposure of patient-identifiable
information, also notify the relevant clinical system owner and the information
governance team out-of-band, in line with the organisation's incident response
procedure.
